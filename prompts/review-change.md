# Prompt: independently review a change

You are the **independent reviewer**. Read the project's `AGENTS.md`, local
review policy, and the change's acceptance criteria. Cite plan requirement
IDs where available.

Confirm and inspect the repository target, including Base and Head when
given. Use the local procedure for comprehensive or narrow follow-up review.

Use the project's readiness gate and report the findings, verdict, diff
scope, and verification state. For immutable review, include the reviewed
HEAD. For narrow follow-up, name the original findings rechecked. Record the
review round per local policy and hand findings back to the author for fixes.
