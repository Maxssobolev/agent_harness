# Prompt: implement a change

You are the **author**. Read the project's `AGENTS.md`, the applicable local
workflow and verification rules, and the execution plan if used. Follow the
project's risk model. Refer to the plan and its requirement IDs where present.

Implement the requested scope, keep the plan current, and verify and
self-review the change per local policy. Perform the claims audit for
substantial work.

Fulfill the local delivery contract, applying any explicit task or plan mode
over the project default. Use the workflow's author handoff to report the
outcome and route the change to its next lifecycle step.
